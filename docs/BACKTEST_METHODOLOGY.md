# 回测方法学（走期 / 基线 / 多重检验 / 三分段）

## 1. Walk-forward

对每个目标期 t（`min_train` 起）：

1. 特征 = `build_features(draws[:t])`；
2. 模型 A/B/C 即时计算，D 以 stride=50 重训（训练集 < t）；
3. 规则投票只读 `draws[:t]`；
4. 预测写入 `predictions`（`data_cutoff = draws[t-1].issue`）并冻结；
5. **之后**才读 `draws[t]` 计算 Brier / LogLoss / top1 命中 / 红球覆盖。

禁止随机打乱交叉验证；禁止用整段历史先选规律再回测同段并称“样本外”。

## 2. 三分段

| 段 | 占比 | 用途 |
| --- | --- | --- |
| dev | min_train 后 60% | 写规则、看表现（探索） |
| val | 20% | 比较参数/投票阈值 |
| holdout | 20% | **只评估一次**；据此改参数必须换新数据重验 |

弃权门槛（top1 份额 ≥1.8/16、分差 ≥0.06）在回测前冻结，写入 `_meta`。

## 3. 指标

- 多类 Brier = Σ(p_i − y_i)²（均匀基线解析值 = 15/16 ≈ 0.9375）
- LogLoss = −ln p_actual（均匀基线 = ln16 ≈ 2.7726）
- top1 命中率 + Wilson 95% CI（均匀基线 6.25%）
- 红球覆盖：top-m 与开奖重叠数，随机期望 = 6m/33（m=6 → 1.091）
- 弃权率、分段稳定性（四分块 max−min）

判定：模型与基线差异的 CI 跨 0（或命中 CI 含 6.25%）→ **无证据优于随机**。

## 4. 随机基线双轨

- 解析：`baseline.py` 组合数学（C(33,6)×16，超几何红球分布）；
- 模拟：固定种子 MC（`seed=42`，n 与 stderr 一并报告），单测断言 |MC−解析|<5σ。

## 5. 多重检验

- 每次批量评估记录尝试总数 N（如 7 条规则）；
- 同时报原始 p 与 BH-q（`bh_adjust`）；
- 只有 holdout 复评 p<0.05 **且** BH-q<0.05 才可标 `validated`；
- 自动发现（Markov 256 单元、红球对 528 对）同样过 BH；
- 禁止只报成功规律：评分卡全量入库 `experiment_results`。
